# 컷의 배분·間·세로 읽기

사건과 반응을 어떤 순간으로 보여줄지 먼저 정한 뒤, 컷의 크기·형태·간격·풍선을 함께 배치한다. 세로 스크롤에서는 독자가 화면을 움직이는 속도를 선택하므로 종이의 페이지 넘김과 같은 타이밍을 보장할 수 없다. 한국어 원고는 위→아래, 같은 높이에서는 왼쪽→오른쪽의 순서를 따른다.

## 어디서 머물고 다음으로 넘어가는가

마(間)는 인물이 말을 받아들이거나 기다리는 순간, 독자가 표정이나 상황을 읽는 자리다. 큰 거터 하나로 언제나 긴 시간이 생기는 것은 아니다. 정적인 자세, 같은 구도의 반복, 풍선의 도착 순서로도 쉼을 표현한다. 즉답은 한 호흡으로, 침묵 뒤의 말은 그 차이를 읽을 수 있게 배치한다. 모든 페이지에 무언컷을 추가하지 않는다.

메리하리(メリハリ)와 완급(緩急)은 장면의 중요 순간을 전후의 강약 속에 놓는 선택이다. 강한 컷은 크기만 아니라 내용·대비·전후 관계로도 두드러진다. 작은 반응과 큰 광경 중 무엇을 오래 볼지는 작품의 목적에 따른다. 대사량만으로 컷 면적을 자동 배분하지 않는다.

## 여백 네 종류와 경계 세 종류

바깥 원고의 여백은 안쪽 작화 무대와 대비를 만들고, 컷 사이 간격은 장면을 나누거나 이어 읽게 하며, 컷 안의 빈 면은 표정·글자·행동을 드러내고, 풍선 안 여백은 문구를 읽게 한다. 각각의 기능을 유지한다. 안쪽 무대는 생성예산 집중 외에 선택적 경계 넘기의 공간을 확보하려는 목적도 있다.

출력 가장자리·안쪽 작화 무대·개별 컷 테두리를 구별한다. 돌출 표현은 현재 채택한 형식 프로필이 허용하는 범위에서 선택한다. 반복된 직사각형, 무테, 겹침, 비대칭은 각각 역할이 있으며 다양성을 위한 쿼터는 없다. 모든 인물을 작게 줄여 얻은 공백이 얼굴과 연기를 없애면 목적에 맞지 않는다.

## 현재 작품과 기존 경험치

컷 수·전체 길이·마무리는 최신 콘티와 작품의 독자 경험을 따른다. 8~10컷이나 12~15컷 같은 옛 제작 예를 이야기의 의무 구조로 사용하지 않는다. 정보·홍보 작품에서 부록·CTA를 별도로 두던 이유는 본편의 감정적 종결을 보호하기 위해서였다. 해당 요소를 요청한 작품에서 사용하며, 일반 만화에 자동으로 추가하지 않는다.

아래 거터 값은 이전 제작의 참고 처방을 보존한 것이다. 이번 조사로 최적값을 검증한 것은 아니며 사용자 채택 배치와 실제 출력의 크기·내부 여백을 먼저 본다. 이유가 미확인인 수치를 공용에서 삭제하거나 새 업계 표준으로 부르지 않는다.

최종 합본은 선택본의 읽는 순서를 유지하고, 이미 포함된 여백에 같은 간격을 두 번 더하지 않는다. 업로드 제한은 해당 작업에서 확인하며 원본을 보존한 파생본을 안전한 공백이나 페이지 경계에서 분할한다. 페이지 번호·부록 헤더·JPG는 목적에 맞게 선택한다.
