# 컷 배치 퇴고

대사와 장면을 다듬은 뒤, 실제 생성 입력을 확정하기 전에 독자가 화면을 읽으며 겪을 흐름과 시선의 무게중심을 설계한다([작법 퇴고](CRAFT_REVIEW.md)의 ‘전편 → 장면 → 컷’ 순서 참고). 크기가 같은 사각형 컷만 기계적으로 반복하면 결정적인 광경과 짧은 반응이 똑같은 무게로 읽히기 쉽다. 독자가 처음 시선을 둘 곳, 오래 머물 곳, 빠르게 미끄러져 내려갈 곳을 구별해 주는 과정이 컷 배치 퇴고다.

## 두 가지 제작 프로필의 구별 (합치지 않는다)

공개 저장소에는 이전 세대의 **전체 페이지 프로필**과 최신 **분리 가능한 1~2컷 시트 프로필**이 함께 기록되어 있다. 두 방식은 생성 단위와 여백의 역할이 다르므로 규칙을 하나로 섞지 않고 작업 프로필에 맞춰 구별해 쓴다.

1. **전체 페이지 프로필 (기존 페이지 단위 재현 범위)**
   - 큰 흰 원고 안에 **폭 약 60%·높이 약 78%의 내부 그림 영역**을 두는 표현 예산을 사용한다. 컷 수와 모양의 자유는 이 내부 영역 안에서 설계하며, 비율을 적을 때는 내부 그림 영역·개별 컷·전체 원고 중 어디를 기준으로 삼았는지 명시한다. 국소적인 인물·식자 넘침(돌출)은 강조 연출로 활용한다.
   - 이 프로필은 한정된 생성 토큰을 좁은 그림 영역의 핵심 표현에 모으려는 **‘할당 토큰 집중 가설’**(검증된 모델 내부 기제가 아니라 작업상 채택한 가설)을 바탕으로 한다. 따라서 실제 생성 요청에도 이 전략을 설명하고, 핵심 연기·대사·소품에 묘사를 집중하며 나머지 바깥 영역을 완성된 흰 여백으로 남겨 달라고 요청한다.
   - 2026-09-12 수학자툰이나 Amazon × OpenAI 사례 등 기존 페이지 단위 작품의 채택 입력과 검증은 해당 작품을 재현하는 범위로 보존한다.

2. **분리 가능한 1~2컷 시트 프로필 (최신 컷 기반 제작 흐름)**
   - 한 번에 전체 페이지를 조립하는 대신, **나중에 컷 단위로 깨끗하게 분리할 수 있는 1~2컷 시트 후보**를 생성해 사용자가 고른 뒤, 별도의 **세로 편집 단계**에서 각 컷의 표시 크기·좌우 정렬·컷 사이 간격을 조립한다([컷 기반 제작](CUT_BASED_PRODUCTION.md) 참고).
   - 생성 시트 안의 내부 배치(분리를 위한 안전 여백과 컷 구성)와 독자가 최종적으로 읽는 세로 스크롤 배치는 서로 다른 단계다. 특정 작품에서 사용한 `1024x1536` 크기, 컷 수, 고정 중앙 흰띠 폭, 인물 수 상한, 의상, 배율과 간격 수치를 다른 모든 작품의 고정 규칙으로 복사하지 않는다.

## 장면의 무게와 읽는 순서 설계

작가는 전체 이야기의 흐름과 앞뒤 장면의 상태, 대사의 말맛과 목표 감정을 읽고 컷의 점유·크기·위치와 식자 배치를 함께 고른다. 정보가 집중될 곳과 반응·침묵으로 비워 둘 공간을 실제 생성 입력에 전달하고, 글자와 말풍선은 발화의 강도와 스마트폰 가독성에 맞춰 크기를 정한다.

작은 반응 컷, 시원하게 펼친 스플래시, 좌우 한쪽으로 힘을 준 구도, 칸 밖에 놓인 문장, 경계를 넘어서는 인물이나 효과, 고요하게 비어 있는 배경 모두 의도를 전달하는 표현 수단이다. 반대로 똑같은 크기의 컷을 반복하는 구성이 무표정한 대비나 코미디의 박자를 살려 준다면 그 이유를 밝혀 그대로 유지한다.

콘티(`image_ready_conte.md`)에는 매 컷 별도의 보고서를 새로 만드는 대신, 기존 콘티 메모 안에 원하는 독자 경험, 그림 영역의 점유와 위치, 그림·글자의 읽는 순서, 여백과 경계의 역할 및 선택 이유(WHY)를 간결하게 남긴다. 모든 연출 기법을 한 작품에 다 쓸 필요는 없으며, 장면을 읽는 데 의미가 있는 결정만 설명하면 충분하다. 대사량과 반응 연기가 좁은 공간을 두고 다투면 컷 분리, 시트/페이지 추가, 식자 위치 조정 또는 위임된 범위의 대사 퇴고를 검토한다.

편집자(Codex)는 실제 원고나 후보 이미지에서 시선·가독성이 충돌하는 지점을 짚고, 의도한 효과와 가능한 해법의 대가를 작가·사용자에게 전달한다. 원문 대사와 화자·순서가 정확히 들어갔는지는 기술 검증으로 확인하고, 배치가 만들어낸 실제 독자 경험은 사람의 눈으로 판단한다.

## 선택 후 세로 편집의 호흡

후보 컷을 선택한 뒤 최종 표시 크기·좌우 위치·컷 사이 거리를 조립할 때는 [호흡과 간격](PANELING_AND_PACING.md) 및 [컷 기반 제작](CUT_BASED_PRODUCTION.md)을 기준 삼아 실제 선택 이미지와 대조한다. 개별 컷 이미지 안에 이미 들어 있는 상하 여백과 컷 사이에 새로 더할 바깥 간격(거터)을 구별하고, 빠른 응답·반응·공개·침묵·장면 전환의 역할에 맞춰 연결 거리를 정한다. 마감과 업로드용 무손실 분할은 [업로드와 전달 규격](UPLOAD_DELIVERY.md)을 따른다.
