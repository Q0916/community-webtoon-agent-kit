## 단계별 진행

이번 작품의 매뉴얼·예시와 완료 조건을 연결한다. 각 단계 진입 시 해당 문서와 직전 결과를 읽고, 종료 시 실제 적용 결과로 체크한 뒤 다음 단계 문서를 읽는다. 유효한 통과 결과는 재사용하고 변경의 영향을 받는 항목만 다시 확인한다. 공개 검증기(`validate_project.py` 등)의 `PASS`나 자료 첨부 자체를 창작 퇴고나 실제 화면 확인으로 대신하지 않는다.

## 현재 단계의 실제 적용

필요한 항목만 추가한다. 단순히 문서를 ‘읽음’이라 적거나 기술 검증을 통과한 것만으로 실제 원고·이미지 확인을 대신하지 않는다.

- [ ] 실제 입력 또는 결과에서 이번 완료 조건을 확인했다. 근거:
- [ ] 완료·남은 문제·다음 행동을 갱신했다.
- [ ] 다음 단계의 매뉴얼·예시를 읽었다. 다음 단계 / 문서:

이 문서는 제작자 내부 기록이다. AGY 의뢰는 짧은 자연어와 실제 작품·자료로 전달한다. 기존 사용자 판단 경계를 유지하며 체크리스트 항목마다 사용자에게 새 보고서나 재승인을 요구하는 절차로 만들지 않는다.
