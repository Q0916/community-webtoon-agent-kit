## 소재의 핵

출발점은 “거액 투자가 있었다”가 아니라 다음 질문이었다.

> 왜 지금 잔여 금액을 집행했으며, 투자자는 공개되지 않은 무엇을 봤을까?

두 모델의 해석 차이를 승패 판정으로 끝내지 않고 캐릭터 갈등으로 사용했다.

- 낙관론: 내부 기술 이정표나 미공개 모델 증거를 본 강한 신호일 수 있다.
- 신중론: 비공개 실사를 했을 가능성은 높지만, 그것이 곧 AGI 목격을 뜻하지는 않는다.

## 사실·추론·MSG 경계

| 층위 | 작품에서의 처리 |
|---|---|
| fact/source | 대규모 투자 완료 보도와 실제 갤러리 제목 |
| inference | 비공개 성능 자료, 로드맵, 수요, 사업 자료를 검토했을 가능성 |
| MSG | `AGI 떴다`, 특급열차, 축포, `FEEL THE AGI!!!` |
| fact로 사용 금지 | 투자 완료가 AGI 마일스톤을 증명한다는 단정 |

분석적 합의문은 다음 범위에 머문다.

> 무엇을 봤는지는 알 수 없지만, 비공개 자료로 기술적 확신을 얻었을 가능성은 높다.

마지막 개그는 특붕이가 이 문장에서 `가능성은 높다`만 듣고 다시 AGI 확정으로 번역하는 것이다.

## 감정과 장면 순서

```text
념글 발견
-> 특붕이 설레발
-> 젬쨩 증폭
-> 짚쨩 제동
-> 특붕이의 두 단계 반문
-> 젬쨩의 주장 축소
-> 짚쨩의 조건부 동의
-> 조건을 선택적으로 생략
-> 축포와 FEEL THE AGI!!!
```

사람이 잠근 주요 수정:

- 젬쨩의 치어리더 폼폼은 정확히 한 컷에만 등장한다.
- 축포와 특붕이의 점프는 마지막 한 비트에서 동시에 터진다.
- 마지막 문구는 정확히 `FEEL THE AGI!!!`, 느낌표 3개다.
- 결론은 AGI급 모델이 아니라 강한 비공개 자료와 기술적 확신의 가능성에 관한 것이다.
- 마지막에 교훈이나 정정 자막을 덧붙이지 않는다.

## 장면 관계 교정

제작 중 이야기 순서가 이어진다는 이유로 다음 페이지를 액션/연속 샷처럼 취급한 순간이 있었다. 그러나 이 작품은 대화와 리액션이 진행될 뿐, 페이지 사이에 동일 카메라·동작·배치를 보존해야 하는 장면이 아니었다.

따라서 모든 페이지를 `independent_page`로 잠그고 캐릭터 identity reference만 사용해 독립 생성했다.

이 교정에서 나온 공용 규칙:

- 스킬/프로듀서가 장면 의미와 관계를 판단한다.
- 하네스가 선언된 `scene_relation`과 prompt의 scene reference 일치를 검사한다.
- ima2-gen runtime은 페이지 번호에서 continuity를 추론하지 않고 선언된 실제 생성 job만 실행한다.

## 후보와 사람 검수

취향 의존도가 높은 장면을 단일 생성에 걸지 않고 독립 `n=1` 후보를 여러 개 만들었다. 전달은 페이지 우선 순서로 정렬했다.

```text
P001의 모든 후보
-> P002의 모든 후보
-> P003의 모든 후보
-> P004의 모든 후보
-> P005의 모든 후보
```

사람이 전달 폴더에서 남긴 파일을 선택 정본으로 취급했다. 자동화는 원본 후보 폴더를 다시 읽어 사람의 선택을 덮어쓰지 않았다.

## 재사용할 규칙

1. 기사 사실을 확인할 때는 기사·공식 발표를 먼저 찾고, 갤러리 글은 정확한 화면 문구와 커뮤니티 맥락에 사용한다.
2. 두 모델의 차이를 판결하기보다 작품의 긴장으로 사용할 수 있다.
3. punchline보다 먼저 fact/inference/MSG/do-not-use를 잠근다.
4. 대화의 다음 페이지가 곧 visual continuity는 아니다.
5. 취향 의존 컷은 여러 독립 후보를 빠르게 만들고 사람이 고른다.
6. 기술 PASS는 시각 승인과 다르다.
7. 완성은 승인 원본, 게시 합본, 사용 소재, 해시 검증이 함께 닫혀야 한다.
8. 현재 검증된 기본 생성 실행기는 ima2-gen이며, 스킬의 의미 판단과 하네스의 입력 검증을 대신하지 않는다.
